# Stack
- **Plataforma:** .NET 10.
- **Lenguaje:** C# 14.
- **Pruebas:** xUnit.
- **Sustitutos de dependencias en pruebas:** NSubstitute.
- **Interfaz de ejecución:** aplicación de consola.
## Comandos
- Compilar la solución: `dotnet build`.
- Ejecutar las pruebas: `dotnet test`.
## Convención de pruebas
- Nombrar cada prueba `Metodo_Escenario_Resultado`.
- Terminar el nombre con el identificador del requisito funcional, por ejemplo `_RF03`.
